### On-Device Computer Vision & Model Quantization

#### 👁️ [CIFAR_Lens](https://github.com/Marvyoha/CIFAR_Lens) — Flagship On-Device Vision App
*A high-speed, privacy-first mobile vision application running quantized neural networks locally on iOS & Android.*
- **Tech Stack:** Flutter, `tflite_flutter`, `image_picker`, Custom Quantized TFLite Model from [pytorch-tflite-quantisation](https://github.com/Marvyoha/pytorch-tflite-quantisation).
- **Key Features:**
  - **Zero-Latency Local Inference:** Runs 100% offline on-device without cloud network roundtrips.
  - **Preprocessing Alignment:** Matches PyTorch tensor normalization bounds (`[0.0, 1.0]` float scaling) in Dart to eliminate inference drift.
  - **Uncertainty Guardrail:** Softmax probability gating (`CONFIDENCE_THRESHOLD = 0.65`) that flags ambiguous inputs as "Uncertain" to prevent false positive classifications.

#### 🔬 [pytorch-tflite-quantisation](https://github.com/Marvyoha/pytorch-tflite-quantisation) — Model Compression & Benchmarking Pipeline
*An end-to-end deep learning pipeline for training, compressing, and benchmarking PyTorch CNNs for edge deployment.*
- **Tech Stack:** PyTorch, ONNX, TensorFlow Lite (`TFLiteConverter`), Scikit-Learn, Matplotlib.
- **Key Features:**
  - **Custom CNN & Early Stopping:** 3-layer compact CNN with Dropout and `EarlyStopping` (restoring best validation weights).
  - **Full INT8 Representative Quantization:** Calibrates activation ranges using a 100-sample representative dataset to compress FP32 weights into 8-bit integers.
  - **Multi-Metric Evaluation:** Side-by-side performance comparison across `.pth`, `.onnx`, and `.tflite` measuring Accuracy, Precision, Recall, ROC-AUC, latency (ms), and disk footprint reduction.
